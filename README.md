# Incremental

This project is a learning project that tries to end with a cool playable incremental game.

# Installation
## Project setup
```
npm install
```

## Run dev server
```
npm run server
```
## Compiles and minifies for production
```
npm run build
```

## Lints and fixes files
```
npm run lint
```
